# Документация

## Purpose
Единая точка входа в документацию репозитория: архитектура, сборка, API, эксперименты и материалы магистерской работы.

## Assumptions
- Симулятор разрабатывается как долгоживущий исследовательский проект.
- Документация описывает факты текущего состояния и принятые решения; результаты экспериментов не выдумываются.

## Decisions
- Все документы пишутся кратко (≈1 экран), инженерным стилем.
- В каждом документе присутствуют секции `Assumptions / Decisions / Next steps`.

## Next steps
