## Purpose
Зафиксировать тему, цели и задачи магистерской работы и их связь с MVP симулятора.

## Assumptions
- Цель проекта: симулятор в Unity для обучения управлению беспилотным транспортом.
- MVP: 1 трасса, 1 ТС, API, запуск обучения из Python.

## Decisions
- Тема: разработка расширяемого симулятора для обучения нейросетевых моделей управления на трассе.
- Цели: воспроизводимость, расширяемость, измеримость результатов.
- Задачи (черновик):
  - определить требования MVP и контракты данных (наблюдения/действия/метрики);
  - реализовать среду (трасса, сброс, измерение прогресса);
  - реализовать ТС (физика, управление, сенсоры);
  - организовать эксперименты (конфиги, артефакты, сравнение);
  - подготовить интеграционные точки для обучения.
