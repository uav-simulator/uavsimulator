# Список сокращений

В настоящей диссертации применяются следующие сокращения и условные обозначения с соответствующими расшифровками. Сокращения приведены в алфавитном порядке: сначала латиница, затем кириллица.

| DI | Dependency Injection — внедрение зависимостей |
| DR | Domain Randomization — рандомизация параметров среды |
| DTO | Data Transfer Object — объект передачи данных |

| GPU | Graphics Processing Unit — графический процессор |
