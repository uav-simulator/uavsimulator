## Purpose
Спецификация API симулятора для MVP и расширений.

## Assumptions
- API — контракт между Unity средой и внешними инструментами (обучение/эксперименты/тесты).

## Decisions
- Спецификация фиксирует:
  - действия управления (руль/газ/тормоз) и их диапазоны;
  - наблюдения (изображение + численные параметры) и единицы;
  - события и причины завершения эпизода;
  - версионирование контракта.

## Next steps
- После согласования диапазонов и форматов синхронизировать с `docs/api.md`.
