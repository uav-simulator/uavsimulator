# Преддипломная практика

Этот раздел фиксирует материалы преддипломной практики по магистерской работе, которые напрямую связаны с развитием `uav-simulator`.

## Контекст

Магистерская работа посвящена разработке расширяемой программной платформы симуляции в Unity для задач обучения и `sim-to-real`.

На этапе преддипломной практики основной фокус такой:
- довести продуктовый контур `train -> install -> activate -> run`;
- подготовить экспериментальную карту и сценарий `A -> B`;
- получить и оценить модель управления в `unity-sim`;
- подготовить перенос на реальную робототехническую платформу.
