Sim-to-real платформа для роботизированной платформы

Это стартовая документационная точка проекта. Платформа объединяет Unity-симулятор, физический стенд, единый backend, единый операторский Web UI и исследовательский слой для sim-to-real экспериментов.

Канонический состав документации сейчас хранится в репозитории в каталоге docs/. Этот сайт пока служит лёгкой публичной entrypoint-страницей и будет расширяться по мере стабилизации структуры документации.

Что является ядром

  • Unity runtime как виртуальный контур платформы
  • Physical runtime как реальный контур платформы
  • Единый operator backend
  • Единый operator UI
  • Unified runtime contract

Что входит в исследовательский слой

  • Python SDK и automation
  • Jupyter notebooks
  • ROS2 bridge
  • Training / inference сценарии

Ближайшие цели MVP

  • Formalized unified contract
  • CLI и server/headless запуск
  • Production-ready plugin path
  • GitHub Pages, CI/CD и docs hygiene
Актуальные исходные markdown-документы находятся в репозитории проекта. Следующий этап — вынести сюда канонические разделы: архитектуру, API, operator flow, Unity runtime и research tooling.
