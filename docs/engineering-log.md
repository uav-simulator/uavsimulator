# Инженерный журнал

**Что это**  
Хронологический журнал изменений и каталог отдельных task-файлов.

**Для кого**  
Для разработки, аудита изменений и восстановления контекста по уже выполненным задачам.

**Статус**  
Актуальный рабочий лог. Не является быстрым пользовательским входом в продукт.

**Проверено по**  
`docs/tasks.md`, `docs/tasks/`

## Основные точки входа
- [Журнал работ](tasks.md)
- Каталог задач: `docs/tasks/`

## Когда сюда идти
- Нужно понять, почему было принято конкретное техническое решение.
- Нужно найти историю появления команды, сценария, API или plugin ID.
- Нужно зафиксировать новую работу по проекту.
