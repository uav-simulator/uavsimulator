## Purpose
Учёт ассетов, источников и лицензий, чтобы избежать юридических рисков и потери воспроизводимости.

## Assumptions
- В проект будут добавляться внешние модели/текстуры/материалы.
- Для каждого внешнего ассета должна быть фиксирована лицензия и источник.

## Decisions
- Для каждого ассета фиксируем:
  - источник (URL/репозиторий/пакет);
  - автор/правообладатель (если известен);
  - лицензия и условия использования;
  - место в проекте (путь в `Assets/`).
- Нельзя добавлять ассеты с неясной лицензией в ветку, используемую для релиза/демонстрации.
