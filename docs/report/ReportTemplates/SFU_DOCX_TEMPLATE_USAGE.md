# Шаблон DOCX по СТУ 7.5–07–2021

## Что сделано

Подготовлены два варианта шаблона:

- `sfu_template_from_2024.docx` — **приоритетный шаблон**, собранный на базе
  уже защищенного отчета `Отчет по практике 2024.docx` (те же стили и layout);
- `sfu_academic_template.docx` / `sfu_report_template.docx` — универсальная версия;
- `build_template_from_report_2024.py` — генерация шаблона из отчета 2024;
- `build_sfu_docx_template.py` — генерация универсального шаблона.

Шаблон рассчитан на:

- отчеты по практике;
- магистерские/преддипломные текстовые документы (как базовая заготовка с корректными стилями).

## Нормативная основа

Требования взяты из `docs/SFU-STU.pdf`, в том числе:

- A4, поля: левое 30 мм, правое 10 мм, верх/низ 20 мм;
- Times New Roman 14;
- межстрочный интервал 1.5;
- абзацный отступ 12.5 мм;
- выравнивание основного текста по ширине;
- нумерация страниц по центру внизу, титульный лист в нумерации учитывается, но номер на нем не выводится.

## Стили (вынесены отдельно)

В шаблоне определены именованные стили:

- `SFU Body` — основной текст;
- `SFU Structural Heading` — структурные заголовки (`ВВЕДЕНИЕ`, `ЗАКЛЮЧЕНИЕ`, `ПРИЛОЖЕНИЕ А`);
- `SFU Heading 1` — заголовок раздела;
- `SFU Heading 2` — заголовок подраздела;
- `SFU Table Caption` — подпись таблицы;
- `SFU Figure Caption` — подпись рисунка;
- `SFU List Dash` — перечни;
- `SFU Bibliography` — список источников;
- `SFU Title Center`, `SFU Title Small` — элементы титульного листа.

## Как пересобрать шаблон

Рекомендуемый вариант (на базе сданного отчета 2024):

```bash
source .venv/bin/activate
python docs/report/practice/build_template_from_report_2024.py
```

Результат:

- `docs/report/practice/sfu_template_from_2024.docx`

Альтернативный вариант (универсальный):

```bash
source .venv/bin/activate
python docs/report/practice/build_sfu_docx_template.py
```

Результат:

- `docs/report/practice/sfu_academic_template.docx`
- `docs/report/practice/sfu_report_template.docx`

## Как использовать

1. Скопируйте `sfu_template_from_2024.docx` в новый документ.
2. Заполняйте только содержимое, не меняя стили вручную.
3. Для разделов/подразделов и подписей используйте соответствующие `SFU*` стили.
4. Перед сдачей удалите демонстрационные строки и примеры из каркаса.

## Практические правила для новых отчетов

- Для реальной сдачи по СФУ приоритетнее использовать не универсальный шаблон, а принятый документ-донор того же типа.
- Генератор итогового `docx` держать в той же папке, что и сдаваемый документ, и явно задавать в нем имя итогового файла.
- Черновой академический текст держать рядом в `md` или в структурированных константах генератора, чтобы затем переиспользовать его в следующих отчетах и в магистерской диссертации.
- После каждой существенной правки проверять не только текст, но и верстку: титульный лист, содержание, правые табы, разрывы страниц, переносы длинной темы.
- Если Word нестабилен при обновлении содержания, для сдаваемого артефакта допустимо фиксировать статическое содержание с корректными уровнями и номерами страниц.
