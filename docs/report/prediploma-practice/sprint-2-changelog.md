## Цель этапа
Реализовать продуктовый контур `train -> install -> run` для модели управления `A->B` в `unity-sim`, включая backend API и web-ui управление моделями.

## План фактической фиксации
- backend: model registry (`upload/list/activate/active`) и autopilot API (`start/stop/status`);
- frontend: вкладка `Model Control` (upload, activate, start/stop autopilot);
- training: базовый Python pipeline с ONNX-артефактом и метаданными;
- валидация цикла: `train -> upload -> activate -> start autopilot`.
