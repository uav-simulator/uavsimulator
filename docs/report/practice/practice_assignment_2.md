# Задание на учебную практику

**Направление подготовки:** 09.04.04 Программная инженерия  
**Профиль:** Инженерия интеллектуальных систем  
**Тема практики:** Разработка единого WebUI-драйвера и web-системы управления роботизированной платформой Keyestudio KS0223 для реального стенда и Unity-симулятора

## 1. Цель практики

Получить практические навыки проектирования, разработки и интеграции программного обеспечения для управления роботизированной платформой в двух режимах исполнения: на физическом стенде Keyestudio KS0223 и в Unity-симуляторе, с единым пользовательским интерфейсом, каналами телеметрии и эксплуатационной документацией.

## 2. Основные задачи

1. Проанализировать существующие каналы взаимодействия с платформой KS0223 на Raspberry Pi и внешнее API Unity-симулятора.
2. Разработать backend-сервис на ASP.NET Core с поддержкой двух runtime-режимов: `real-robot` и `unity-sim`.
3. Реализовать единый web-интерфейс оператора для управления движением, камерой и исполнительными узлами без разделения frontend по режимам.
4. Организовать единый контур отображения статуса соединения, healthcheck, камеры, телеметрии и журналирования сессий.
5. Интегрировать расширенный канал сенсоров и исполнительных узлов для реального KS0223, включая HC-SR04, сервопривод и LED-панель.
6. Подготовить контейнеризированный запуск web-комплекса и эксплуатационные инструкции по локальному запуску, обновлению и сопровождению.
7. Выполнить диагностику и устранить критическую проблему нестабильной работы канала управления после reboot Raspberry Pi.
8. Подготовить отчёт, приложения, листинги и материалы для презентации результатов как части общего sim-to-real проекта магистерской работы.

## 3. Планируемые результаты

1. Рабочий WebUI-драйвер для управления KS0223, поддерживающий переключение между реальным стендом и Unity-симулятором.
2. Документированная архитектура продукта с описанием backend runtime providers, web-интерфейса и каналов интеграции.
3. Проверенный сценарий восстановления стабильной работы реального стенда после reboot Raspberry Pi.
4. Набор эксплуатационных материалов для запуска, обновления, диагностики и развития системы.

## 4. Используемые технологии

- Backend: ASP.NET Core (.NET 8), SignalR, BackgroundService, HTTP JSON API.
- Frontend: React, TypeScript, Vite, MUI.
- Симуляция: Unity 6000.1.8f1, внешний runtime API (`/health`, `/contract`, `/reset`, `/step`).
- Интеграция: TCP, UDP, HTTP, SSH, JSONL-логирование.
- Инфраструктура: Docker, Makefile, Linux systemd.

## 5. Форма отчётности

1. Отчёт по практике с описанием архитектуры, реализованных модулей, результатов и направлений дальнейшего развития.
2. Презентация по итогам выполненной работы.
3. Демонстрация работоспособности единого WebUI-драйвера для `real-robot` и `unity-sim`.
