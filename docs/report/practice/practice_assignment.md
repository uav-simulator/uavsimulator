# Задание на учебную практику

**Направление подготовки:** 09.04.04 Программная инженерия  
**Профиль:** Инженерия интеллектуальных систем  
**Тема практики:** Разработка программного драйвера и web-системы управления роботизированной платформой Keyestudio KS0223

## 1. Цель практики

Получить практические навыки проектирования, разработки и интеграции программного обеспечения для управления роботизированной платформой, включая сетевое взаимодействие, пользовательский интерфейс и обработку телеметрии.

## 2. Основные задачи

1. Изучить протокол и режимы обмена данными с платформой KS0223 по TCP.
2. Разработать backend-сервис для отправки команд управления и приёма данных от робота.
3. Реализовать web-интерфейс оператора для управления движением, камерой и исполнительными узлами.
4. Организовать отображение телеметрии и журналирование команд/событий.
5. Подготовить контейнеризированный запуск проекта (Docker + Makefile).
6. Выполнить диагностику и устранить сетевые проблемы после перезапуска Raspberry Pi.
7. Подготовить итоговую документацию и материалы для презентации результатов.

## 3. Планируемые результаты

1. Рабочий программный комплекс управления KS0223 с веб-доступом.
2. Документированная архитектура и описание реализованных модулей.
3. Проверенный сценарий восстановления стабильной работы после reboot.
4. Набор эксплуатационных инструкций для запуска и обновления.

## 4. Используемые технологии

- Backend: ASP.NET Core (.NET 8), SignalR.
- Frontend: React + TypeScript + Vite + MUI.
- Интеграция: TCP/UDP, HTTP, SSH (диагностика), JSONL-логирование.
- Инфраструктура: Docker, Makefile, Linux systemd.

## 5. Форма отчётности

1. Отчёт по практике (описание целей, хода выполнения, результатов).
2. Презентация по итогам выполненной работы.
3. Демонстрация работоспособности программного комплекса.
