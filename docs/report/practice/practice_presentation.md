# Презентация по практике

## Слайд 1. Тема и цель

**Тема:** Разработка драйвера и web-системы управления роботизированной платформой Keyestudio KS0223.  
**Цель:** Создать устойчивый программный контур управления роботом с визуальным интерфейсом, телеметрией и документированным запуском.

## Слайд 2. Постановка задачи

- Управление движением и камерой робота с Mac.
- Получение и отображение данных датчиков.
- Обеспечение устойчивой работы после reboot.
- Упаковка решения для удобного запуска и обновления.

## Слайд 3. Архитектура решения

- **Raspberry Pi (KS0223):** MainControl.py, FramesSend.py, sensor bridge.
- **Backend (.NET):** адаптер команд, API, SignalR, логирование.
- **Frontend (React):** пульт, камера, телеметрия, LED, логи.
- **Инфраструктура:** Docker/Makefile для единого запуска.

## Слайд 4. Реализованный backend

- Подключение к роботу по TCP (`5051`).
- Передача команд управления и fail-safe `STOP`.
- Healthcheck, статусы соединений, обработка ошибок.
- JSONL-логи сессий и событий.

## Слайд 5. Реализованный frontend

- Управление с клавиатуры и экранных кнопок.
- Панель камеры и настраиваемый overlay.
- Управление HC-SR04, камерой и LED-матрицей.
- Вкладки телеметрии/сенсоров/логов.

## Слайд 6. Работа с телеметрией

- Приём данных с sensor bridge.
- Отображение доступных сенсоров в UI.
- Диагностика деградации канала при потере данных.

## Слайд 7. Ключевая проблема и диагностика

- После reboot периодически пропадало управление по TCP.
- Выявлен сетевой конфликт на Pi: `dhcpcd` + `networking.service` с legacy static `eth0`.
- Симптом: нестабильные IP/маршруты при рабочем видеопотоке.

## Слайд 8. Внесённый патч стабильности

- Отключён legacy static профиль `/etc/network/interfaces.d/eth0`.
- Отключён `networking.service`, оставлен единый менеджер сети `dhcpcd`.
- Сохранён rollback и backup-конфигураций.
- Результат подтверждён реальным reboot-тестом.

## Слайд 9. Итоги практики

- Получен рабочий программный комплекс управления KS0223.
- Обеспечен воспроизводимый запуск и обслуживание.
- Подготовлена документация для эксплуатации и развития проекта.

## Слайд 10. Дальнейшее развитие

- Расширение API для автономных сценариев движения.
