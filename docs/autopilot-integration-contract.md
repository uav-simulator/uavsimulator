# Autopilot Integration Contract


## Базовый принцип
Автопилот подключается к платформе как внешний клиент и не меняет product-core интерфейсы.

Он должен работать поверх:
- продуктового backend API;
- Unity runtime API;
- Python tooling и bridge-слоёв

без разрастания специальных веток в frontend.

## Что автопилот получает
- наблюдения и telemetry через существующие продуктовые интерфейсы;
- camera frame через текущий camera flow;
- возможность отправлять управляющие команды через нормализованный control path.

## Граница интеграции
Интеграция автопилота идет поверх существующих продуктовых интерфейсов и не требует отдельного обязательного frontend-потока.

## Текущий статус интеграции
- продуктовые интерфейсы уже позволяют внешнему модулю читать состояние и управлять runtime;
- отдельного продуктового UI-потока управления автопилотом в проекте сейчас нет;
- research-layer вокруг автопилота допускается, но остаётся вторичным.
