# KS0223

## Текущие vehicle ID
- `vehicle.prometeo.sport.v1`
- `vehicle.arcade.blue.v1`
- `vehicle.arcade.red.v1`
- `vehicle.arcade.gray.v1`
- `vehicle.arcade.purple.v1`

## Контракт и управление
- тип привода: дифференциальный (`left/right PWM`);
- дополнительные каналы идут через `ControlCommand.extensions`;
- базовый продуктовый канал `throttle/steer/brake` остаётся совместимым интерфейсом для симулятора и общих агентов.

## Наблюдения и телеметрия
Текущий KS0223-контур использует:
- фронтальную камеру;
- speedometer;
- ultrasonic distance;
- line tracker;
- battery/power estimate.

Для camera fallback используется `jpeg + base64` в `StepResult.frame`.

## Физический стенд
Реальный транспортный слой KS0223 остаётся отдельным hardware adapter-ом вне Unity core.

ROS2 интеграция также остаётся отдельным bridge-слоем и не меняет core DTO.
