## Purpose
Зафиксировать профиль интеграции реального робота Keyestudio KS0223 в симулятор как plugin-first решение.

## Assumptions
- Этот профиль не меняет core API симулятора.
- Robot-specific детали передаются через `ControlCommand.extensions` и `VehicleState.telemetry`.
- Источник аппаратных фактов: официальная документация Keyestudio KS0223.

## Decisions
- Идентификатор плагина (предложение): `vehicle.ks0223.v1`.
- Дополнительные визуальные варианты (тот же KS0223 контракт):
  - `vehicle.ks0223.arcade.blue.v1`
  - `vehicle.ks0223.arcade.red.v1`
  - `vehicle.ks0223.arcade.gray.v1`
  - `vehicle.ks0223.arcade.purple.v1`
- Тип привода: дифференциальный (`left/right PWM`), диапазон нормализован к `[-1..1]`.
- Канал наблюдений для MVP:
  - фронтальная камера (RGB);
  - базовое состояние (`pose/speed/timestamp`);
  - plugin telemetry в стиле CARLA/ROS2 naming.
- Привязка контракта:
  - `ControlCommand.extensions["drive.left_pwm_norm"]`
  - `ControlCommand.extensions["drive.right_pwm_norm"]`
  - `ControlCommand.extensions["control.throttle_norm"]` (опционально)
  - `ControlCommand.extensions["control.steer_norm"]` (опционально)
  - `ControlCommand.extensions["control.brake_norm"]` (опционально)
  - `ControlCommand.extensions["camera.pan_norm"]` (опционально)
  - `ControlCommand.extensions["camera.tilt_norm"]` (опционально)
- Телеметрия v1:
  - `sensor.speedometer.mps`
  - `sensor.ultrasonic.front.m`
  - `sensor.line_tracker.s1_norm`..`sensor.line_tracker.s5_norm`
  - `power.battery.voltage_v`
  - `power.battery.current_a`
  - `power.motor.estimated_w`
- Кадр камеры:
  - `StepResult.frame.frameId = "camera/front/image_raw"`
  - формат `jpeg`, кодировка `base64` (MVP HTTP fallback).
- Реальный транспортный слой (Raspberry Pi):
  - отдельный Python hardware adapter;
  - под капотом может использовать GPIO/PWM напрямую;
  - TCP/UDP команды из официального app-протокола допускаются как fallback/отладка, но не как основной путь для обучения.
- ROS2 интеграция:
  - отдельный bridge процесс (`python/bridges/ros2_bridge.py`);
  - включается опционально, не меняет core DTO/Unity transport.

## Next steps
- Подготовить `DeviceContractDescriptorAsset` для KS0223 и добавить его в plugin registry.
- Реализовать Python adapter с watchdog и аварийным стопом.
- Добавить smoke-тест: `reset -> 20 step -> stop` на реальном роботе с ограничением PWM.

## Notes (hardware baseline)
- В примерах KS0223 присутствуют GPIO-пины для TB6612 и line-tracking/ultrasonic модулей.
- В app-протоколе есть команды движения/камеры (`DirForward`, `DirLeft`, `CamUp`, `CamDown` и т.д.).
