# Вклад в проект

## Purpose
Описать минимальные правила работы с репозиторием, чтобы проект развивался предсказуемо.

## Assumptions
- Unity проект находится в `src/UnityProject/uav-simulator`.
- Сцены и ассеты меняются в Unity Editor, но фиксация изменений делается через Git.

## Decisions
- Не коммитим мусор: crash dumps, `.DS_Store`, `Library/`, `Temp/`, `Logs/`.
- Документация и решения фиксируются:
  - прогресс: `docs/tasks.md`;
  - задачи: `tasks/` (одна задача — один файл);
  - индекс docs: `docs/README.md`.
- Код: идентификаторы на английском; русский допускается только в комментариях.
